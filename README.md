# 🚀 Antigravity Mobile (Полная автономность на Android)

**Antigravity Mobile** — это полноценный автономный порт среды и AI-агента Antigravity в виде нативного **Android APK**-приложения.

Приложение работает **полностью самостоятельно на вашем смартфоне** без необходимости держать включенным компьютер!

---

## 📱 Главные возможности на смартфоне

1. **🧠 Автономный AI-агент (Agentic Loop)**:
   - Прямое подключение к Google Gemini API (`gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.5-flash-lite`, `gemini-1.5-pro`).
   - Отображение **Thinking (хода мыслей и рассуждений)** в раскрывающемся аккордеоне в реальном времени.
   - Поддержка многошаговых задач (до 25 циклов автономной работы с возможностью продолжения или остановки).

2. **🛠️ Полный набор инструментов (Tools)**, выполняемых прямо на Android:
   - `run_command`: выполнение любых консольных команд (`sh`, `git`, `python`, системные утилиты Linux/Android) через встроенный шелл устройства.
   - `view_file`: чтение файлов проекта с поддержкой диапазонов строк.
   - `write_to_file`: создание и запись исходного кода файлов проекта.
   - `replace_file_content`: хирургическое редактирование кода в существующих файлах.
   - `list_directory`: навигация по каталогам.
   - `search_code`: рекурсивный поиск по кодовой базе.

3. **💻 Встроенный Android Терминал**:
   - Интерактивная консоль `/system/bin/sh` прямо внутри приложения.
   - История команд, быстрые кнопки (`ls -la`, `pwd`, `uname -a`, `df -h`, `python`).

4. **📁 Менеджер проектов и Редактор кода**:
   - Дерево файлов рабочей директории на телефоне (`/sdcard/AntigravityProjects`).
   - Полноэкранный редактор кода с панелью быстрых спецсимволов (`{ } ( ) [ ] = : ; / \ $ _`).
   - Кнопка экспорта всего проекта в **ZIP** для быстрой отправки в Telegram или на диск.

5. **🎤 Голосовой ввод и тактильный отклик**:
   - Диктовка команд голосом через микрофон смартфона.
   - Приятная вибрация (haptic feedback) и звуковые сигналы при завершении задач.

6. **⚡ Официальный Antigravity CLI (`agy`) в Termux**:
   - Полноценный терминальный интерфейс Antigravity CLI прямо на Android.
   - Установка в одну команду: скачивает официальный Google Antigravity binary (v1.3.2 ARM64) и связывает его с Termux.
   - Работает прямо в терминале: пишите `agy` и сразу работайте с агентом, кодом и файлами.

---

## 📱 Запуск `agy` CLI в Termux (В одну строку!)

1. Откройте **Termux** на смартфоне.
2. Вставьте и запустите команду:
   ```bash
   pkg update -y && pkg install -y git && git clone https://github.com/bbqabsolute/antigravity-mobile.git && cd antigravity-mobile/termux && bash install.sh
   ```
3. Готово! Теперь в любой папке Termux работает команда **`agy`**:
   * **`agy`** — интерактивный терминальный AI-агент Antigravity.
   * **`agy -p "напиши скрипт..."`** — быстрое выполнение задачи без лишних окон.
   * **`agy --help`** — просмотр всех ключей и доступных моделей.

> Если телефон пишет *"Приложение заблокировано"* или *"Не поддерживается"*, перейдите в:  
> **Настройки -> Безопасность и конфиденциальность -> Автоблокировка (Auto Blocker)** -> временно выключите тумблер для установки сторонних APK.

## ⚙️ Вход через Google

1. При открытии приложения или веб-интерфейса нажмите **«Войти через Google»**.
2. В нативном приложении открывается системный диалог выбора Google-аккаунта вашего устройства.
3. В веб/Termux режиме открывается официальное окно входа Google.
4. Авторизация сохраняется локально на смартфоне. Никаких ручных ключей API!

---

## 🛠️ Сборка APK из исходников

* Запустите `build_apk.bat` или `python build_apk.py`.
* Скрипт собирает готовый и подписанный `Antigravity-Mobile.apk` с таргетом `minSdkVersion="26"` и `targetSdkVersion="35"` (полная поддержка Android 8 — Android 16).
